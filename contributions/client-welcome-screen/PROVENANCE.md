# Provenance and sanitization

This is a focused extraction of the Clinton Public Library client welcome-screen
work, adapted onto public Libki client revision
cdca236eecce9891715dc1b575cbd01661abd477. It is not a copy of the private
repository or its history.

Code changes use the upstream GPL-3.0-or-later license; see [LICENSE](LICENSE).
The simple white information icons originated in the library's GPL client
modifications. The three demonstration background images were supplied with
the Clinton welcome-screen work and are copied here without alteration.
Their embedded C2PA metadata identifies OpenAI gpt-image generation; that
provenance is preserved. They depict the library/community aesthetic; they are not screenshots of patron
activity. Libraries can replace them with their own artwork. This contribution
does not claim ownership of Libki or endorsement by its maintainers.

Production settings, deployment scripts, host lists, internal routes, tenant
identifiers, authentication secrets, patron data and private Git history are
excluded. All policy wording is fictional demonstration content, and external
links use the reserved library.example.org documentation hostname.
Screenshots come from a rebuilt native login-window harness using those examples,
not a production workstation or a web mockup.
